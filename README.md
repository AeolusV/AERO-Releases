# AERO

**简体中文** · [English](README.en.md)

让任务留在视野里。

AERO 是为 Codex Desktop 设计的 Windows 桌面伴侣。六盏任务灯、一条轻巧的悬浮栏，让你少一点切换，多一点专注。

![AERO 完整控制栏](images/full-bar.png)

[下载 Beta 8](https://github.com/AeolusV/AERO-Releases/releases/tag/v0.1.0-beta.8) · [使用指南](USAGE.md) · [更新内容](CHANGELOG.md)

## 看得见进展，也留得住专注。

六盏灯同时呈现任务状态。悬停看清工作区与任务名称，轻点就回到对应对话。任务完成，灯色由蓝转绿；也可以开启轻柔的提示音。

![AERO 迷你状态栏](images/mini-bar.png)

## 常用操作，就在手边。

新建、继续、暂停、处理请求，或按任务调整推理强度。忙于其他工作时，收成迷你栏，只留下需要的一眼信息。两种控制栏都可以拖动，也能吸附在屏幕边缘。

## 你的桌面，你的 AERO。

浅色与深色分别选择，灯色、声音和控件顺序随你。把常用的留在手边，把不常用的收起来。

![AERO 外观设置](images/appearance.png)

## 说声 Hey Codex，接着聊。

AERO 在本地识别唤醒词。听到 Hey Codex 后暂停聆听、让出麦克风，并打开 Codex Voice。首次所需文件可在设置中准备，之后的唤醒识别可以离线使用。Codex Voice 对话需要联网，并使用 Codex 自身的账号与额度。

[配置语音唤醒](USAGE.md#hey-codex)

## 开始使用

下载 Release 中的 Windows x64 ZIP，完整解压，打开 `AERO.exe`。需要已安装并登录的 Codex Desktop。当前 Beta 未签名，下载后请核对来源与校验文件。
